03 — Projects

RAG System

Document Intelligence System

A production-ready RAG pipeline that ingests PDFs, indexes them into a vector store, and answers natural language queries with source attribution. Built to replace expensive document review workflows.

Python LangChain ChromaDB OpenAI FastAPI
Retrieval Accuracy ~87% Latency <1.2s

Problem

Teams spending hours manually searching through 100+ page technical PDFs for specific answers.

Solution

Chunked documents using semantic splitting, embedded with text-embedding-3-small, stored in ChromaDB, with MMR retrieval to reduce redundancy.

Key Decision

Chose MMR over pure similarity search to improve diversity of retrieved chunks, which reduced hallucinations by avoiding repetitive context.

Lesson Learned

Chunk size dramatically affects quality. 512 tokens with 50-token overlap outperformed both larger and smaller sizes for this domain.

AI Agent

Research Assistant Agent

An autonomous agent that receives a research topic, searches the web, summarizes findings, cross-references sources, and produces a structured report — with tool-use and self-critique loops.

LangGraph Python Tavily API GPT-4 Pydantic
Tasks Automated 12 steps Output Quality High

Architecture

LangGraph state machine with nodes: Planner → Web Search → Summarizer → Critic → Reporter. Conditional edges handle retry logic.

Challenge

Preventing hallucination when sources conflict. Solved with a Critic node that compares claims across sources before final synthesis.

Key Decision

Used structured Pydantic outputs at each node boundary. This made debugging 10x easier and prevented silent failures mid-pipeline.

Result

Reports that used to take 3-4 hours manually now complete in under 5 minutes with comparable quality for structured domains.

Machine Learning

Sentiment Analysis Pipeline

End-to-end ML pipeline for multi-class sentiment analysis on Persian and English text. Includes data preprocessing, fine-tuned BERT variant, evaluation suite, and a FastAPI inference endpoint.

PyTorch HuggingFace FastAPI Persian NLP BERT
F1 Score 0.84 Inference ~80ms

Problem

Existing sentiment tools fail on Persian text due to morphological complexity and lack of training data.

Approach

Fine-tuned ParsBERT on a curated Persian sentiment dataset with data augmentation. Added an ensemble layer for uncertain predictions.

Challenge

Class imbalance (70% neutral). Addressed with weighted cross-entropy loss and oversampling minority classes.

Deployment

Wrapped in FastAPI with async inference, input validation, and a simple confidence threshold to route uncertain cases to a human review queue.

Automation

LLM-Powered Resume Analyzer

Analyzes resumes against job descriptions using structured LLM extraction. Outputs a match score, missing keywords, and specific improvement suggestions. Processes PDFs or raw text.

Python OpenAI Pydantic PyPDF2 Streamlit
Structured Output 100% Processing Time <3s

Architecture

Two-stage pipeline: PDF extraction + normalization, then structured LLM analysis using function calling for guaranteed JSON output.

Key Insight

Using JSON schema via function calling reduced parsing errors to zero vs. freeform text prompts which failed ~15% of the time.

Challenge

PDF extraction quality varies wildly. Solved with a pre-processing step that detects and handles scanned PDFs vs. digital PDFs differently.

Result

Used by 20+ beta testers who reported better interview callback rates after implementing the suggestions.
